What's New in v2.2 🚀

Massive Polish & Deep Sync • Aug 06, 2026

v2.2

Massive Polish & Deep Sync

Smart Cross-Module Sync

  • Humanized Auto-Closure: Resolved RMA & WAN tickets now log proper engineer names instead of robotic text.
  • Email Alerts Recovered: Hardware & Network tickets now successfully shoot green success emails upon resolution.
  • Location-Based Routing: CC emails automatically route to Dehradun or Noida team based on the asset's location.
  • IP Manager Fixed: Dehradun IPs are now accurately synced by fixing case-sensitivity and column-mapping bugs.

Premium UI Refinements

  • Vibrant Audit KPI: Removed dull grey filters from the "IT Sec Audit" card; it now glows a premium green when submitted.
  • Symmetrical Pop-ups: Redesigned the audit signature block to be fully responsive and perfectly aligned without text cutting.
  • Read-Only Ticket Details: Replaced the redundant "Resolve" button on closed tickets with a "View Details" button showcasing final remarks.
  • WhatsApp-Ready Copy: The inventory copy button now generates a clean, structured, full-detail format for easy sharing.
  • Uniform Login Cursor: Removed the zoom effect on the login page cursor to maintain professional consistency across the platform.
v2.1

Smart Audit Dashboard & Speed Boost

Premium UI Upgrade

  • Modern Layout: Replaced the old boxy design. Added color-coded status strips, sleek buttons, and a spacious box for typing summaries easily.
  • Mobile Friendly: Fixed spacing issues on mobile phones. The audit checklist now perfectly fits smaller screens without looking squeezed.

Lightning Fast Loading

  • Instant Drafts: Added local caching. Your saved audit drafts will now open instantly (in 0.1s) without making you wait for the server.

Accurate Scores & Bug-Free Emails

  • Smart Calculation: Fixed the math behind compliance scores. Marking a point as 'N/A' will no longer mess up your final percentage.
  • Stable Email Layouts: Rewrote the email structure. Audit reports will now look perfect on Outlook and mobile phones without breaking.
v2.0

The Smart Sync & Deep Audit Engine

Automated License Engine

  • Hardware Tagging: Manual data entry for software usage is gone! You can now directly tag licensed software to individual computers inside the Hardware menu.
  • Live Deployment Breakdown: The Software menu now automatically calculates total used licenses and shows exactly which User, Hostname, and Department is using them in real-time.

Deep Security Audit Protocol

  • Color-Coded Checklist: Critical keywords in the audit checklist are now color-highlighted so auditors instantly know what to focus on (e.g., Red for unauthorized software).
  • Executive Summary: Added a handover-style summary box with a strict 100-word minimum limit and a live color-changing visual counter to ensure comprehensive reporting.

Smart Filtering & Dashboards

  • Developer PC Quick Filter: Instantly find all development machines without manual searching using the new dedicated virtual location filter.
  • Advanced Hygiene Scanner: The "Hygiene" button actively catches and filters out dummy/junk data (like "N/A" or "Unassigned") to keep your database 100% accurate.
  • Intelligent Validity Widgets: Software details adapt automatically, showing a "License Deficit" widget for OS & Utilities, and a glowing "Expiry Countdown" for Antivirus.
v1.6

Cohesive Ecosystem & UI Polish

Chromatic App Identities

  • Visual Hierarchy: Main Dashboard is pure Blue, while inner apps have distinct colors (Indigo for Inventory, Teal for Switch, Rose for IP).
  • Color-Coded KPIs: Header titles and data numbers inside each application now dynamically match that app's specific core theme.

Smart Data Filtering

  • Clickable KPI Cards: Tapping on any stat card (like 'Operational' or 'Reserve') now instantly filters the data table below it.
  • Quick Reset: Simply click on 'Inventory' or the 'Total' card to reset the table back to the full view.

Hardware Acceleration

  • Zero-Jitter Cursor: Replaced the old DOM-based cursor with a native SVG cursor using OS-level GPU acceleration.
  • Non-Obtrusive Tooltips: Tooltips on header icons are now hidden on mobile to prevent accidental touch interruptions.
v1.5

Platform Upgrade

Performance & Unified UI

  • Zero-Latency Engine: Loading screens eliminated via Optimistic Caching.
  • Smart Iconography: Automatically assigns relevant emojis to devices, holidays, and ISP events.

Leave Hub Insights

  • Interactive Policies: Tap any Leave KPI card to instantly view your quota and usage.
  • Smart Long Weekends: The tracker now automatically predicts 3-Day weekend opportunities.
