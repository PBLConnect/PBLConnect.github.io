Official Release Notes

What's New in v1.3 🚀

Workflow Evolution • Jun 30, 2026

v1.3

Major Update

Strict Audit Governance

  • Access Control (RBAC): Only assigned auditors can resolve compliance findings. Super Admin overrides removed.
  • View-Only Mode: IT Head and non-assigned engineers can only view audit remarks without edit permissions.

Smart Semantic Engine

  • Dynamic Status: Tickets now display context-aware tags (e.g., LINK DOWN vs RESTORED, ACTION REQ. vs SECURED).
  • Email Workflow Overhaul: Deprecated the legacy email parsing system. Tickets are directly resolved from the UI.
  • UI Enhancements: Optimized card layouts, fixed overlapping modals (Z-Index), and updated naming to 'Workstation ID'.
v1.2.5

Global Audit Trail

Added a 'Recent Changes' hub to track every IP and ISP switch across all PCs globally. Resolved RMA & WAN tickets are safely locked with Admin Key requirements.

v1.2

Security Update

Bi-Monthly Audits: Introduced a strict 12-point IT Security checklist that automatically generates high-priority tickets for non-compliance.

v1.1

Base Integration

Successfully linked IT Inventory, IP Manager, and Switch logs for automated data syncing across the platform.
