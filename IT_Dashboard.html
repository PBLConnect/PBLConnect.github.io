What's New in v2.5 🚀

Unified Master Exports & Streamlined Operations • Sep 01, 2026

v2.5

Unified Master Exports & Ecosystem Polish

Master Export Suite

  • Platform-Wide Unified Exports: Added high-fidelity XLSX & PDF exports across all modules—AssetDB (26-column), IP Manager (10-column allocation dump), Switch Map, WAN Logs, and RMA Tracker with dynamic branding.
  • Streamlined Audit Protocol: Removed the redundant inventory export button from the IT Sec Audit modal to maintain a clean, dedicated compliance workflow.

Real-time Sync & Mobile UX

  • Live Roster Reactivity: Resolved state caching in Team Roster; online/offline status and shift active counts now recalculate dynamically every second without page refreshes.
  • 2-Row Mobile Toolbars: Re-engineered toolbars across both AssetDB and IP Manager into balanced 2-row mobile layouts with unified Export dropdowns and frosted visionOS popovers.
v2.3.5

Neo-SaaS Experience & Network Core

Interactive Ecosystem

  • visionOS Glassmorphism: Dropdowns, Modals, and Cards now feature true frosted glass (`backdrop-blur-3xl`), Neumorphic inset borders, and ambient colored glowing Orbs.
  • Alive Animations: Added shimmering skeleton loaders, fluid text scaling via `clamp()`, and reactive Neon-Ripple bursts on every click.

Mobile-First Architecture

  • Floating App Dock: The footer is now an ultra-slim iOS-style floating dock. Included a fully integrated Network Popover to check Ping, IP, and Internet Speed instantly.
  • Semantic Tickets: Ticket History is 100% visually semantic. RMA/Network issues natively force Purple/Sky colors across avatars, pills, and watermarks. Truncation (`...`) is eliminated.
  • Live Inventory Export: Added a new "HW/SW Inventory" button in the IT Sec Audit modal to instantly download a multi-tab Excel snapshot. It hides smartly on submitted audits but remains permanently accessible to the Head of IT.
  • Dynamic Filter Counter: AssetDB now features a pulsating result counter pill that instantly displays the exact number of hardware/software records matching your active filters.

Massive Polish & Deep Sync

Smart Cross-Module Sync

  • Humanized Auto-Closure: Resolved RMA & WAN tickets now log proper engineer names instead of robotic text.
  • Email Alerts Recovered: Hardware & Network tickets now successfully shoot green success emails upon resolution.
  • Location-Based Routing: CC emails automatically route to Dehradun or Noida team based on the asset's location.
  • IP Manager Fixed: Dehradun IPs are now accurately synced by fixing case-sensitivity and column-mapping bugs.

Premium UI Refinements

  • Uniform Login Cursor: Removed the zoom effect on the login page cursor to maintain professional consistency across the platform.

Smart Audit Dashboard & Speed Boost

Premium UI Upgrade

  • Modern Layout: Replaced the old boxy design. Added color-coded status strips, sleek buttons, and a spacious box for typing summaries easily.

Lightning Fast Loading

v2.0

The Smart Sync & Deep Audit Engine

Automated License Engine

  • Hardware Tagging: Manual data entry for software usage is gone! You can now directly tag licensed software to individual computers inside the Hardware menu.
  • Live Deployment Breakdown: The Software menu now automatically calculates total used licenses and shows exactly which User, Hostname, and Department is using them in real-time.

Deep Security Audit Protocol

  • Color-Coded Checklist: Critical keywords in the audit checklist are now color-highlighted so auditors instantly know what to focus on (e.g., Red for unauthorized software).
  • Executive Summary: Added a handover-style summary box with a strict 100-word minimum limit and a live color-changing visual counter to ensure comprehensive reporting.

Smart Filtering & Dashboards

  • Developer PC Quick Filter: Instantly find all development machines without manual searching using the new dedicated virtual location filter.
  • Advanced Hygiene Scanner: The "Hygiene" button actively catches and filters out dummy/junk data (like "N/A" or "Unassigned") to keep your database 100% accurate.
  • Intelligent Validity Widgets: Software details adapt automatically, showing a "License Deficit" widget for OS & Utilities, and a glowing "Expiry Countdown" for Antivirus.
