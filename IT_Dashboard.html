Official Release Notes

What's New in v1.2 🚀

Security & Auto-Alerts Update • Jun 25, 2026

v1.2

Latest Additions

Bi-Monthly Security Audit

  • New Sec Audit Box: Introduced a dedicated 'Sec Audit' KPI box on the dashboard. Click it to easily open the new 12-point security checklist.
  • Strict Access: Only the assigned engineer can fill and submit their own audit report.
  • Tamper-Proof: Once submitted, the audit locks permanently with the exact Date and Time.
  • Better Controls: Added smooth Pass/Fail buttons and a new Risk Severity (Low/High) selector.

Smart Automation

  • Auto-Ticketing: If any audit point fails, the system automatically creates a High-Priority IT ticket.
  • Smart Alerts: The system now sends automatic reminders and Overdue warnings based on the date.
  • UI Fixes: Cleaned up the Analytics layout and fixed the issue where the chart tooltip was getting cut.
v1.1

Previous Update

Connected Systems: Linked all IT modules (Inventory, IP Manager, Switches) so data automatically syncs everywhere without manual typing. Upgraded the overall design.
