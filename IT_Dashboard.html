Official Release Notes

What's New in v1.1 🚀

Major Update: June 22, 2026

Global Interoperability Engine

Poora IT Portal ab ekdum interconnected ban chuka hai! 🔄 Ek module mein data modify karo, baaki sab jagah automatically sync ho jayega. IPs aur Hostnames ki manual data entry block kar di gayi hai taaki Single Source of Truth (SSOT) strict tarike se enforce ho sake. 🛡️

IT Dashboard

  • Added: Tickets par ab live IP, Switch Port aur Location ke badges real-time mein dikhenge. 📍
  • Added: Apps par premium kinetic hover aur frosted glass zoom effect lagaya gaya hai. ✨
  • Fixed: Ticket details ko ultra-compact 2-row layout mein fix kiya, no more unnecessary scroll. 📐

IP Manager

  • Added: Hostnames ke liye smart auto-sync searchable dropdown laga diya hai. 🔍
  • Added: Active connections ab visually pop-out (highlight) honge taaki clear focus rahe. 🔴
  • Fixed: Mobile View ko optimize karke 1-page compact layout banaya bina vertical scroll ke. 📱

IT Inventory

  • Added: IP Manager se seedha Live IP fetch hoga as a Read-Replica. Manual typing locked! 🔒
  • Added: Asset details dekhne ke liye premium iOS-style sliding drawer (Bento cards) add kiya hai. 🗂️
  • Fixed: Mobile par scroll karte hi KPI cards smooth animation ke sath hide ho jayenge. 📉

Switch Map

  • Added: Active ports par ab Asset IDs ka smart dropdown aayega, hardcoded text nahi. 🔌
  • Fixed: Screen ke edge par tooltip ka katna (clipping issue) permanently fix kar diya. ✂️
  • Fixed: Mobile floating card par tap karte hi gayab hone wala Event propagation bug solved. 🐞

RMA Tracker

  • Added: Hardware faults ke liye highly granular aur categorized dropdown (Taxonomy) add kiya. 📊
  • Added: Hostname select karte hi Serial Number (S/N) auto-fill hoga. No more typos! ✅
  • Fixed: Purane plain-text data ko naye emoji-based dropdown se automatically map kar diya gaya hai. 🧩

WAN Monitor

  • Added: Dynamic ISP color coding ke sath premium layout design kiya gaya. 🎨
  • Added: Mobile par scroll event detect karke KPI cards ko collapsible banaya gaya. 📱
  • Fixed: Backend array mapping ko fix karke exact database values se align kar diya hai. ⚙️
