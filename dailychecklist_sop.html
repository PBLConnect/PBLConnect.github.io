2. Interacting with Modules

Swipes, Sliders & Smart Inputs

Nayi app mein checkboxes ko hata kar advanced touch gestures aur tactile elements daale gaye hain. Har ek action par aapko Haptic Vibration (Phone vibration) feel hogi.

Servers & Cloud Services

Mobile par kisi bhi service ko ON karne ke liye uspar Swipe Right → karein. Desktop par simple click karein.
Agar koi server Maintenance par hai, toh Card ke right side top par bane chote Wrench (🛠️) icon par click karein. Yeh box ko Yellow kar dega.

ISP Network Sliders

Download (Blue) aur Upload (Purple) speed ko set karne ke liye DJ style sliders ko drag karein.
Fiber vs RF: Naye update mein aap network medium select kar sakte hain. Fiber select karne par max speed apne aap adjust ho jayegi.
Ticket Rule: Agar speed 50% se kam set ki gayi, toh slider RED ho jayega aur ek naya Ticket Input box open hoga. Complaint No. daalna zaruri hai.

Security Audits (AV & USB)

Antivirus (Sophos/Seqrite) aur USB port block random client PC par check karne hain. Box par click karte hi ek Popup khulega. Aapko Target PC ka naam type karna padega (e.g., PBLNET005) tabhi verify button unlock hoga.

Facility & Fire Safety

AC cooling verify karne ke alawa Fire Safety toggle ON karein. ON karte hi ek Location Select Dropdown aayega. Isme Noida/Dehradun ke specific pillars/floors ki list hai. Aapne physical tour me jis extinguisher ko check kiya hai, wahi location select karein.

3. Shift Specific Action Items

Engineer Responsibilities

Niche diye gaye tasks sirf usi shift mein dikhai denge jiski timing chal rahi hai. In fields ke andar inputs daalna track kiya jata hai.

Morning Shift (Noida - Anil)

  • Temp Sync: Server room temp slide karke set karein. Bahar ka weather API ke through automatically aayega.

  • Prod PCs: Floor verify karein. Agar koi system raat se ON chhut gaya hai, toh box red hoga aur slide-down command line me PC ka ID likhna hoga.

  • Manual Backups: DC aur ADC ka backup button click karein, aur Completion Time (e.g. 02:15 AM) input box mein type karein.

  • eTokens & FTP: Safe se 15 tokens issue karein aur Client FTP sync status ko verify karke click karein.

General Shift (Dehradun - Deependra)

  • Temp Limit: Dehradun ke liye max temp limit 28°C set ki gayi hai. Usey exceed karne par alert aayega.

  • Guard Register Audit: Security desk par physical register ki entry ko CCTV timings ke sath random cross-verify karna mandatory hai.

  • FTP Server Start: Ensure karein ki subah PBLDD027 properly power ON ho chuka hai.

Evening Shift (Noida - Ashok)

  • eTokens Vault: Morning me issue hue sabhi tokens wapis Vault (Safehouse) mein count karke secure karein.

  • FTP Monitoring: Active client sync check karein. Toggle ON karne par ek input box aayega, jisme Client A Uploading type ka status likhna hai. Yeh automatically final report me attach hoga.

  • pblnet020 Status: Agar system mein data download chal raha hai toh box Orange rahega, input me Job name daalein. Agar download complete hai toh toggle off karke Green karein (System Shutdown verified).

4. Shift Logs, Handover & Submit

Closing the Cycle

Smart Handover Feature

Bottom mein diye gaye "Shift Logs" text area ka ek special purpose hai. Agar score 100% nahi hai ya koi important pending ticket hai, toh wahan detailed message type karein.

Magic Trick ✨

Jab aap message type karke submit karenge, aur jab agle din/shift mein next engineer (e.g. Ashok) app open karega, toh app usko turant ek Popup Alert dikhayegi ki "Message from Anil: STPI Link down ticket #441 pending". Isse manual WhatsApp message ki zarurat nahi padegi!

5. Top 3 Golden Rules

IT Discipline

1

No Fake Entries: App aapka session duration ("TimeTaken") track karti hai aur report me attach karti hai. Exact physical verification ke baad hi elements tick karein.

2

Auto-Save Rescue: Agar beech mein app band ho jaye ya refresh ho jaye, don't panic. App ka LocalStorage engine form ko auto-save rakhta hai. Wapis aane par sab bhara hua milega.

3

Cloud Status URLs: Email report ke andar ek nayi 🔍 View Report link hogi jisme management click karke aapki report ka ek sundar graphical HTML version web par dekh sakti hai.
